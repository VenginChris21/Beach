How to run the project

 import our sql file to a new database named beach_employee_system
 
copy the code to your localhost or server htdocs folder , for our side it is xammpp/htdocs folder

after all of this open the folder in the localhost server and press the pages folder 

you will see an interface, press new employee registration on the top right corner

input the needed information and press register 

input your username/password in the login form 

then you will reach the employee dashboard 

here you can time in and time out using the buttons 

you can edit your information here using the edit button as shown 

you can log out using the log out button on the top right

for you to access the admin of this system use "admin" and "admin" as the user and password

in the admin section you can fire or delete employees on this part

and you can log out of the admin



PS: when copying files to the htdocs folder use "New" as your mother folder since this is inputed in certain redirections
